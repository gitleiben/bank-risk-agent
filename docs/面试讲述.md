# 面试讲述稿（3 分钟版）

> 讲的时候按「业务痛点 → 我的方案 → 关键决策 → 结果与边界」四段走。
> 不要一上来报技术栈，面试官对"为什么这么设计"的兴趣远大于"你用了什么"。

## 1. 场景与痛点（40 秒）

我在银行做运营监督与风险预警系统做了多年，最清楚一线的两件重复劳动：一是查制度，新人问"夜间异常时段交易几笔算预警、该怎么处置"，要翻几十页文件；二是处置预警工单，一条工单进来要走五步——查规则、查同类案例、查账户画像、给结论、分派岗位，全靠人工。

我做的这个预研项目就是想把这两件事交给 Agent，同时保证两条金融底线：**数据不出域**、**结论可追溯**。

## 2. 我做了什么（50 秒）

一个 Spring Boot 服务，两条主链路：

- **制度问答**：文档按标题感知切分成 30 个片段，混合检索（关键词 + 向量）取 Top4，拼成带 `[1][2]` 标号的上下文，交给本地 Qwen2.5 生成，引用来源由代码回填。
- **工单处置 Agent**：把"查规则、查历史案例、查账户画像、生成分派单"封装成四个 `@Tool` 工具，模型自己决定调哪几个、按什么顺序调，最后强制输出结构化 JSON——风险等级、判定依据、处置动作、分派岗位、引用来源。

模型跑在本地 Ollama，语料和交易数据不出网，这是金融项目能不能用的前提。

## 3. 关键决策（60 秒，这里是加分项）

- **切分按标题，不按字数**。制度文档的语义边界在条款标题处，硬切会把"第八条"的条件和结论切到两个片段，检索出来是半句话。
- **混合检索，不是纯向量**。"4.5 万""十个工作日"这类精确词向量容易被稀释，关键词路（bigram + idf）补上，还能在 embedding 服务挂掉时兜底。
- **引用不让模型自己编**。模型只写标号，来源和得分由系统填，否则引用不可信，整个答案在金融场景就废了。
- **降级优先于超时**。Spring AI 默认重试 10 次，模型没起来时一次问答要卡两分钟，我加了 700ms 探针，不可用就秒级降级成"只给制度原文"。
- **结构化输出**。银行不要"一句话建议"，要能落表、能分派、能审计的字段。

## 4. 结果与边界（30 秒）

- 检索链路自建 10 条用例命中 10/10，但这是自建语料 + 题库对应，只能证明链路通，**不能当效果指标**——真实数字要等接 ES 向量 + 改写集测完再报。
- 工具目前接的是示例数据，M3 会把这批工具封装成 MCP Server，接真实风控接口。
- 我会明确说这是个人预研，不是银行上线系统。这一点主动说，比被问出来强。

## 高频追问 & 回答要点

**Q：为什么不用 LangChain4j / Spring AI Alibaba 的 Agent 框架？**
A：当前这一版用的是 Spring AI 的 `ChatClient` + Tool Calling，工具编排由模型自主决定；M3 会引入 Spring AI Alibaba Graph 做显式 DAG（意图识别 → 条款检索 → 案例类比 → 处置生成 → 人工确认），因为金融处置流程有强制环节，不能完全交给模型自由发挥。选型理由：Java 生态 + 对流程可控。

**Q：怎么评估效果？**
A：两层。检索层看 TopK 命中率和来源命中（是不是召回对了文件）；答案层看关键要素覆盖率（金额、时限、处置动作是否都在）。改切分参数、改权重前后各跑一遍，做对比。现在 10 条，M4 扩到 40 条并加改写集。

**Q：幻觉怎么控制？**
A：四道：① 检索不到就不答；② 提示词禁止用常识补全、禁止编造条款号；③ 引用由代码回填，模型编不出不存在的来源；④ 结构化输出里"依据"字段必须指向检索结果，否则前端标红走人工。

**Q：本地模型性能够吗？**
A：3B 在结构化输出上偶尔漏字段，7B 稳定得多。金融场景里延迟可以接受，合规不可妥协——数据不出域是硬要求，所以本地模型是起点，不是妥协。真要上生产可以走行内私有化部署的大模型，代码只改 base-url 和 model 名。

**Q：这条链路接真实风控系统要改什么？**
A：工具层换实现（`RiskToolbox` 里三个查询方法改成调现有 REST/Dubbo 接口），加鉴权与审计日志，把 MCP Server 作为统一出口，让其他 Agent 复用同一批工具，避免每个新 Agent 重写一遍取数逻辑。

**Q：为什么用 MCP？**
A：工具接一次、多方复用。现在同一批工具只服务本服务，封装成 MCP Server 后，Claude、Cursor、其他 Agent 都能调，取数逻辑收敛在一处，权限和审计也好管。这也是我简历上"了解 MCP"变成"做过 MCP"的关键一步。
